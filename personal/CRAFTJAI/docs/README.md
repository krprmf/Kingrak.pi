# CRAFTJAI Docs

## Folder Structure

```
docs/
├── research/     — Research findings before big changes
├── plans/        — Implementation plans for big features
├── changelogs/   — Log of what changed and why
```

## Workflow
1. Before a big edit → research in `research/`
2. Plan the approach → write in `plans/`
3. After implementation → log in `changelogs/`
